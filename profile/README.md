# hoko-ai

> **Hands-on AI Infrastructure, Low-Level Proxies, and Developer Tools in Go & PHP.**

`hoko-ai` is an open-source project suite dedicated to building low-level AI infrastructure from scratch. Rather than relying on high-level LLM SDK wrappers, the projects under this organization explore how vector search, streaming proxies, protocol gateways, and safety guardrails work at the network and database layers.

---

## 🛠 Tech Stack

- **Languages:** Go, PHP
- **Databases & Vectors:** PostgreSQL (`pgvector`), MariaDB, Redis (Search / Vector Indexing), Elasticsearch
- **Networking & Web:** Nginx, Server-Sent Events (SSE), HTTP/2, JSON-RPC 2.0
- **Protocols & Standards:** Model Context Protocol (MCP), OpenAI API Specification
